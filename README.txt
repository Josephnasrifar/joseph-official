FREE PUBLISHING WITH GITHUB PAGES:
1. Create a free account at github.com.
2. Create a new PUBLIC repository named joseph-website.
3. Upload index.html and the assets folder (preserving folder structure).
4. In repository Settings > Pages, select Deploy from a branch, main, /(root), Save.
5. GitHub will show your free website address after deployment.

This starter website includes selected releases, an embedded Spotify artist player, official profile links, artist bio, and your supplied photos. Individual song links currently lead to the Spotify artist page; replace with direct track URLs as you gather them. Add individual cover art and official video embeds when available.

Free GitHub Pages hosting uses a github.io address; a custom .com domain typically costs extra.
